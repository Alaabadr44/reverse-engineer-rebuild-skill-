# reverse-engineer-rebuild

A Claude Code skill: reverse-engineer a running reference or legacy system into a verified spec,
recovered business formulas, a gap analysis and a card-based rebuild plan, then run the rebuild
through a gated, test-first pipeline with parallel agents.

## Install

Copy `SKILL.md` and the `references/` folder into a folder named `reverse-engineer-rebuild`:

- personal: `~/.claude/skills/reverse-engineer-rebuild/`
- one project: `<project>/.claude/skills/reverse-engineer-rebuild/`

Restart Claude Code, then run `/reverse-engineer-rebuild` or ask it to analyze a system
by reverse engineering.
